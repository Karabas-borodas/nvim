# Keymaps — конфиг Neovim (vnext)

**Leader:** `<Space>`  
**Local leader:** `,`

---

## Общие и редактор

| Клавиша | Режим | Действие |
|--------|--------|----------|
| `<C-s>` | n | Сохранить файл |
| `<Esc>` | i, n | Снять подсветку поиска и выйти |
| `j` / `k` | n | Движение по строкам с учётом переноса (gj/gk) |
| `<` / `>` | v | Сдвиг выделения, выделение остаётся |
| `<CR>` | n | Переключить fold под курсором (в quickfix — Enter по элементу) |
| `<C-l>` | i | Перепрыгнуть через закрывающий символ ), ], }, " и т.д. |

## Окна (Window) — `<leader>w`

| Клавиша | Действие |
|--------|----------|
| `<leader>ws` | Горизонтальный split |
| `<leader>wv` | Вертикальный split |
| `<leader>wc` | Закрыть окно |
| `<leader>wT` | Переместить окно в новую вкладку |
| `<leader>wr` | Ротация вниз/вправо |
| `<leader>wR` | Ротация вверх/влево |
| `<leader>wH` / `wJ` / `wK` / `wL` | Переместить окно влево / вниз / вверх / вправо |
| `<leader>w=` | Выровнять размеры окон |
| `<leader>wk` / `wj` | Увеличить / уменьшить высоту окна |
| `<leader>wh` / `wl` | Расширить / сузить окно по горизонтали |

**Функция:** управление разбиением экрана, перемещение и изменение размеров окон.

| Клавиша | Действие |
|--------|----------|

### Переключатели UI (Snacks toggle)

Через **Snacks** часть опций редактора и отображения переключается одной клавишей (вкл/выкл). Удобно для быстрой смены режима без захода в настройки.

| Клавиша | Действие | Что делает |
|--------|----------|------------|
| `<leader>ts` | Spell | Включить/выключить проверку орфографии (подчёркивание ошибок, автозамена). |
| `<leader>uw` | Wrap | Включить/выключить мягкий перенос длинных строк по ширине окна (без разрыва строки в файле). |
| `<leader>un` | relativenumber | Включить/выключить номера строк относительно курсора (удобно для прыжков 5j, 12k). |
| `<leader>uC` | cursorline | Подсветка строки с курсором (горизонтальная линия). |
| `<leader>ud` | Диагностики | Показать/скрыть значки и подчёркивания LSP/линтера в буфере. |
| `<leader>ul` | Номера строк | Включить/выключить отображение номеров строк слева. |
| `<leader>uc` | conceallevel | Скрыть/показать «свёрнутые» символы (например `*` в markdown, кавычки в JSON). |
| `<leader>uh` | Inlay hints | Подсказки LSP в коде (типы параметров, переменных) прямо в тексте. |
| `<leader>uD` | Dim | Затемнить неактивные области (например, неактивные окна или невидимый код). |
| `<leader>uZ` | Zen mode | Режим «без отвлечений»: скрыть лишние элементы интерфейса, сфокусироваться на тексте. |
| `<leader>uz` | Zoom | Увеличить/уменьшить текущее окно (занять больше или меньше места на экране). |

## Git (Fugitive + Gitsigns)

**Плагины:** `tpope/vim-fugitive`, `lewis6991/gitsigns.nvim`

**Функция:** **Fugitive** — работа с git из редактора: статус, коммиты, diff, блочный выбор в `:G`. **Gitsigns** — пометки на полях (добавлено/изменено/удалено), навигация по «хукам» (блокам изменений), stage/reset, blame и превью прямо в буфере.

### Fugitive

| Клавиша | Действие | Что делает |
|--------|----------|------------|
| `<leader>gg` | Открыть :G | Открыть окно статуса git (как `git status`), откуда можно переходить к diff, stage, коммиту. |
| `<leader>gl` | GcLog | Открыть лог коммитов (историю) в текущем репозитории. |
| `<leader>gD` | Gvdiffsplit | Открыть вертикальный diff (сравнение версий/веток). |
| `<leader>gf` | 0GcLog | Показать историю коммитов для текущего файла. |

### Gitsigns (в буфере)

Знаки на полях показывают добавленные/изменённые/удалённые строки. **Hunk** — один блок таких изменений.

| Клавиша | Действие | Что делает |
|--------|----------|------------|
| `gj` / `gk` | След./пред. hunk | Перейти к следующему или предыдущему блоку изменений в файле. |
| `<leader>gs` | Stage hunk | Добавить текущий hunk в индекс (git add только этого блока). |
| `<leader>gu` | Unstage hunk | Убрать hunk из индекса (в визуальном режиме — для выделенного диапазона). |
| `<leader>gr` | Reset hunk | Отменить изменения в текущем hunk (вернуть к состоянию последнего коммита). |
| `<leader>gS` | Stage buffer | Добавить в индекс весь текущий файл. |
| `<leader>gR` | Reset buffer | Отменить все изменения в файле (как checkout -- file). |
| `<leader>gp` | Превью hunk | Показать окно с diff текущего hunk. |
| `<leader>gb` | Blame по строке | Включить/выключить отображение «кто и когда изменил» для строки под курсором. |
| `<leader>gd` | Показать удалённые | Inline-показ удалённых строк в изменённом блоке. |

## UI

### Yazi

**Плагин:** `mikavilpas/yazi.nvim`

**Функция:** встроенный TUI файловый менеджер Yazi в плавающем окне.

| Клавиша | Действие |
|--------|----------|
| `<leader>lf` | Открыть Yazi (текущий каталог) |

### Noice

**Плагин:** `folke/noice.nvim`

**Функция:** улучшенная командная строка и отображение сообщений.

| Клавиша | Действие |
|--------|----------|
| `<leader>nn` | Открыть Noice (все сообщения) |

### Colorizer

**Плагин:** `catgoose/nvim-colorizer.lua`

**Функция:** подсветка цветовых кодов (#rrggbb и др.) в буфере.

| Клавиша | Действие |
|--------|----------|
| `<leader>ux` | Вкл/выкл Colorizer |

**Команда:** `:ColorizerToggle`

### Тема

**Плагин:** `folke/tokyonight.nvim`

**Функция:** цветовая схема tokyonight-moon (без отдельных клавиш).

## Статуслайн

**Плагин:** `nvim-lualine/lualine.nvim`

**Функция:** нижняя строка с веткой, diff, диагностикой, LSP, именем файла, кодировкой, макросами, счётчиком слов (для markdown/tex и др.), прогрессом.

*Клавиш нет.*

---

## Mason

**Плагины:** `williamboman/mason.nvim`, `williamboman/mason-lspconfig.nvim`, `jay-babu/mason-nvim-dap.nvim`

**Функция:** установка LSP, линтеров, форматтеров и DAP-адаптеров через UI. Управление через `:Lazy` или команды Mason.

*Отдельных keymaps в конфиге нет.*
