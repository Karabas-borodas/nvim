# Отчёт: сравнение конфигов nvim и nvim.java

**Пути:**
- `~/.config/nvim` — основной конфиг (vnext)
- `~/.config/nvim.java` — конфиг для Java-разработки

---

## 1. Общая структура

| Аспект | nvim | nvim.java |
|--------|------|-----------|
| **Точка входа** | `init.lua` → `vnext.config` | `init.lua` → `core`, `lazy`, `lsp`, `config/terminal`, `keymappings` |
| **Менеджер плагинов** | lazy.nvim (bootstrap в `config/lazy.lua`) | lazy.nvim (bootstrap в `init.lua`) |
| **Структура конфига** | `lua/vnext/config/` + `lua/vnext/plugins/` + `lua/vnext/extra/` | `lua/core/`, `lua/plugins/`, `lua/config/`, `lua/lsp/`, `lua/me/` |
| **Leader** | `<Space>` | не задан явно (по умолчанию `\`) |
| **Local leader** | `,` | не задан |

## 7. Выводы

1. **nvim (vnext)** — универсальный конфиг: Snacks (дашборд + пикеры), blink.cmp, which-key, линтинг/формат, много LSP (без Java), Git (fugitive + gitsigns), flash, outline, отдельные ключи под окна/буферы/файлы.
2. **nvim.java** — заточен под Java: Telescope, nvim-cmp, Trouble, vim-test, DAP и nvim-jdtls, dashboard, wilder, vim-pencil, marks, matchup; меньше «общих» пикеров, больше классических плагинов (Telescope, Trouble, SymbolsOutline).
3. **Клавиши:** в nvim всё завязано на `<leader>` с группами (which-key); в nvim.java — часть через `,` (Telescope), часть через `<leader>`, плюс табы (th/tk/tj и т.д.) и форматирование (Q, `<leader>Q`).
4. **Treesitter** в обоих есть; в nvim — больше грамматик и endwise; в nvim.java клавиша Inspect Tree (`<leader>uI`) в отчёт не попала (её можно добавить в keymappings при необходимости).

Файл отчёта: `~/.config/nvim/отчет.md`.
